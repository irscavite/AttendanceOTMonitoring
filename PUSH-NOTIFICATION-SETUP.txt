ONE-TIME LOGIN + PHONE PUSH SETUP (FLAT FOLDER BUILD)
=====================================================

FOLDER STRUCTURE
----------------
There is NO functions/ folder in this build.
The Cloud Function is stored at the project root as:

  cloud-functions.js
  package.json

The website files, Firebase config, rules, and Cloud Function files are all
inside the same AttendanceOTMonitoring-main folder.

ALREADY CONFIGURED
------------------
- Firebase Auth uses LOCAL persistence. Closing Chrome, refreshing, or reopening
  the same site does not normally log the user out.
- Logout removes this device's push registration before Firebase sign-out.
- Firebase Cloud Messaging (FCM) + service worker are included.
- The provided public Web Push/VAPID key is already configured.
- Background push targets Supervisor, Request Approver, HR, IT, Employee, and
  Internal Chat recipients.
- Tapping a push opens the system and routes to the related page when available.

DEPLOY FROM THIS SAME FOLDER
----------------------------
Open Command Prompt/Terminal inside AttendanceOTMonitoring-main, then run:

  npm install
  firebase login
  firebase use otmonitoring
  firebase deploy

No "cd functions" command is needed.

If Firebase CLI is not installed yet:

  npm install -g firebase-tools

To deploy only the backend + database rules:

  firebase deploy --only functions,database

To deploy only Firebase Hosting:

  firebase deploy --only hosting

IMPORTANT
---------
- Cloud Functions deployment normally requires the Firebase project to use the
  Blaze plan.
- The website must be served through HTTPS for FCM/service-worker background push.
- Persistent login is per browser + website origin. Logout, clearing browser/site
  data, private/incognito mode, account disabling, or browser security policies
  can require login again.

PHONE SETUP (ONCE PER PHONE/BROWSER)
------------------------------------
1. Open the deployed HTTPS site.
2. Sign in.
3. Tap the phone notification button (📲).
4. Tap Allow when the browser asks for notification permission.
5. Keep notifications allowed for the site in the phone/browser settings.
