IT DATA MAINTENANCE - CLEAR EMPLOYEE SCHEDULE INPUT

Added to IT account:
- New Data Maintenance menu.
- Clear All Schedule Input action.
- Requires typing CLEAR SCHEDULE before the destructive action is enabled.

The reset clears only Supervisor > Employee Schedule setup:
- Work Area
- Morning/Night Shift
- Editable Shift In / Shift Out time
- Weekly Day Off

Preserved:
- Employee Master List
- Position / Department / Employment Status
- SL / VL credits
- Firebase Authentication / system accounts
- Attendance records
- OT records
- Leave records
- Historical reports

After reset, affected employees return to Needs Setup and supervisors receive schedule-required notifications so schedules can be entered again.
